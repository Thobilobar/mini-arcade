Mini Arcade privacy

Last updated: 10 October 2026

Mini Arcade is designed as a local-first Telegram Mini App. This project contains no developer analytics, advertising trackers, or developer-operated application backend.

Telegram profile information

When Telegram provides it to the Mini App, the app can read your Telegram display name, username, numeric user ID, language, Premium flag, and profile-photo URL. These fields are used only to personalize the interface and local profile. The app does not treat client-side Telegram profile data as server-verified identity.

Game data stored on your device

  • Game progress, records, coins, settings, daily-challenge history, and profile preferences are kept in one AES-GCM encrypted local vault.
  • On Telegram clients that support Bot API 9.0 storage, the AES key is kept in Telegram SecureStorage (iOS Keychain / Android Keystore) and the encrypted vault is kept in Telegram DeviceStorage.
  • Outside a supported Telegram client, the fallback uses a non-extractable Web Crypto key in IndexedDB and stores only encrypted vault ciphertext in browser local storage.

Network requests

The app loads Telegram's official Mini App bridge and may load your Telegram profile photo from the URL Telegram provides. Your static hosting provider and Telegram can receive ordinary technical request information such as IP address and user agent under their own policies. Mini Arcade itself does not send game progress or profile data to a developer backend.

Deleting local data

Use the full data reset in the Profile screen. It clears the Mini Arcade encrypted vault and its encryption key. Clearing Telegram/browser site data also removes the local copy.

Security boundary

The raw Telegram launch data is used only for local presentation in this static app. If a future version adds accounts, leaderboards, purchases, or any trusted server action, the raw Telegram initData must be validated on that server; a bot token must never be embedded in this frontend.

Young users

The app does not ask for age and does not transmit game progress to a developer backend. Telegram account and platform privacy practices still apply.

حریم خصوصی Mini Arcade

آخرین به‌روزرسانی: ۱۰ اکتبر ۲۰۲۶

Mini Arcade به‌صورت یک مینی‌اپ تلگرام با رویکرد «محلی‌اول» طراحی شده است. در این پروژه تحلیل‌گر توسعه‌دهنده، ردیاب تبلیغاتی یا بک‌اند اختصاصی برنامه وجود ندارد.

اطلاعات پروفایل تلگرام

اگر تلگرام در اختیار مینی‌اپ بگذارد، برنامه می‌تواند نام نمایشی، نام کاربری، شناسه عددی کاربر، زبان، وضعیت Premium و نشانی عکس پروفایل را بخواند. این اطلاعات فقط برای شخصی‌سازی رابط و پروفایل محلی استفاده می‌شوند و به‌عنوان هویت تأییدشدهٔ سروری در نظر گرفته نمی‌شوند.

داده‌های بازی روی دستگاه

  • پیشرفت بازی‌ها، رکوردها، سکه‌ها، تنظیمات، سابقهٔ چالش روزانه و ترجیحات پروفایل در یک مخزن محلی رمزگذاری‌شده با AES-GCM نگهداری می‌شوند.
  • در نسخه‌های پشتیبانی‌شدهٔ تلگرام، کلید رمزگذاری در SecureStorage تلگرام (Keychain در iOS / Keystore در Android) و متن رمز‌شده در DeviceStorage قرار می‌گیرد.
  • خارج از محیط پشتیبانی‌شدهٔ تلگرام، کلید غیرقابل‌استخراج Web Crypto در IndexedDB و فقط متن رمز‌شده در حافظهٔ محلی مرورگر نگهداری می‌شود.

درخواست‌های شبکه

برنامه پل رسمی Mini App تلگرام را بارگذاری می‌کند و ممکن است عکس پروفایل را از نشانی‌ای که تلگرام می‌دهد دریافت کند. سرویس میزبانی و تلگرام می‌توانند طبق سیاست‌های خود اطلاعات فنی عادی درخواست‌ها مانند IP و user-agent را ببینند. خود Mini Arcade پیشرفت بازی یا دادهٔ پروفایل را به بک‌اند توسعه‌دهنده ارسال نمی‌کند.

پاک کردن داده‌ها

از گزینهٔ پاک‌سازی کامل در صفحهٔ پروفایل استفاده کن. این کار مخزن رمزگذاری‌شده و کلید رمزگذاری Mini Arcade را حذف می‌کند. پاک کردن دادهٔ سایت/تلگرام نیز نسخهٔ محلی را از بین می‌برد.
