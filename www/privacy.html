Mini Arcade privacy

Last updated: 13 October 2026

Mini Arcade keeps game progress, settings, and profile preferences encrypted on your device. This page explains what the app can read from Telegram, what remains local, and which normal network requests can still occur.

Telegram profile information

When Telegram provides it to the Mini App, the app can read your Telegram display name, username, numeric user ID, language, Premium flag, and profile-photo URL. These fields are used only to personalize the interface and local profile. The app does not treat client-side Telegram profile data as server-verified identity.

Game data stored on your device

  • Game progress, records, coins, settings, daily-challenge history, and profile preferences are kept in one AES-GCM encrypted local vault.
  • On Telegram clients that support Bot API 9.0 storage, the AES key is kept in Telegram SecureStorage (iOS Keychain / Android Keystore) and the encrypted vault is kept in Telegram DeviceStorage.
  • Outside a supported Telegram client, the fallback uses a non-extractable Web Crypto key in IndexedDB and stores only encrypted vault ciphertext in browser local storage.

Network requests

The app loads Telegram's official Mini App bridge and may load your Telegram profile photo from the URL Telegram provides. Your static hosting provider and Telegram can receive ordinary technical request information such as IP address and user agent under their own policies. When Live Friend multiplayer is enabled, a small signaling service receives WebRTC connection-negotiation messages and ordinary connection metadata so two players can establish a direct encrypted peer-to-peer channel. It does not receive or store game moves, game progress, profile preferences, or Telegram profile data. If direct peer-to-peer connectivity fails and TURN is configured, encrypted WebRTC packets may be relayed by the TURN provider.

Deleting local data

Use the full data reset in the Profile screen. It clears the Mini Arcade encrypted vault and its encryption key. Clearing Telegram/browser site data also removes the local copy.

Security boundary

The raw Telegram launch data is used only for local presentation and local match identity. The signaling service does not use Telegram initData for authorization and is not an authoritative game server. If a future version adds accounts, leaderboards, purchases, cloud sync, or any trusted server action, raw Telegram initData must be validated on that server; a bot token must never be embedded in this frontend.

Young users

The app does not ask for age. Game progress remains in the encrypted local vault; Live Friend signaling is limited to connection setup and does not store gameplay. Telegram, the static host, and any configured WebRTC/TURN provider have their own platform privacy practices.

حریم خصوصی Mini Arcade

آخرین به‌روزرسانی: ۱۳ اکتبر ۲۰۲۶

Mini Arcade پیشرفت بازی‌ها، تنظیمات و ترجیحات پروفایل را به‌صورت رمزگذاری‌شده روی دستگاه نگه می‌دارد. این صفحه توضیح می‌دهد برنامه چه اطلاعاتی را از تلگرام می‌خواند، چه داده‌هایی محلی می‌مانند و چه درخواست‌های عادی شبکه ممکن است انجام شوند.

اطلاعات پروفایل تلگرام

اگر تلگرام در اختیار مینی‌اپ بگذارد، برنامه می‌تواند نام نمایشی، نام کاربری، شناسه عددی کاربر، زبان، وضعیت Premium و نشانی عکس پروفایل را بخواند. این اطلاعات فقط برای شخصی‌سازی رابط و پروفایل محلی استفاده می‌شوند و به‌عنوان هویت تأییدشدهٔ سروری در نظر گرفته نمی‌شوند.

داده‌های بازی روی دستگاه

  • پیشرفت بازی‌ها، رکوردها، سکه‌ها، تنظیمات، سابقهٔ چالش روزانه و ترجیحات پروفایل در یک مخزن محلی رمزگذاری‌شده با AES-GCM نگهداری می‌شوند.
  • در نسخه‌های پشتیبانی‌شدهٔ تلگرام، کلید رمزگذاری در SecureStorage تلگرام (Keychain در iOS / Keystore در Android) و متن رمز‌شده در DeviceStorage قرار می‌گیرد.
  • خارج از محیط پشتیبانی‌شدهٔ تلگرام، کلید غیرقابل‌استخراج Web Crypto در IndexedDB و فقط متن رمز‌شده در حافظهٔ محلی مرورگر نگهداری می‌شود.

درخواست‌های شبکه

برنامه پل رسمی Mini App تلگرام را بارگذاری می‌کند و ممکن است عکس پروفایل را از نشانی‌ای که تلگرام می‌دهد دریافت کند. سرویس میزبانی و تلگرام می‌توانند طبق سیاست‌های خود اطلاعات فنی عادی درخواست‌ها مانند IP و user-agent را ببینند. وقتی حالت Live Friend فعال باشد، یک سرویس کوچک سیگنالینگ فقط پیام‌های لازم برای برقراری اتصال WebRTC و اطلاعات فنی عادی اتصال را دریافت می‌کند تا دو بازیکن یک کانال مستقیم و رمزگذاری‌شده بسازند. این سرویس حرکت‌های بازی، پیشرفت بازی، ترجیحات پروفایل یا اطلاعات پروفایل تلگرام را دریافت یا ذخیره نمی‌کند. اگر اتصال مستقیم ممکن نباشد و TURN تنظیم شده باشد، بسته‌های رمزگذاری‌شدهٔ WebRTC ممکن است از سرویس TURN عبور کنند.

پاک کردن داده‌ها

از گزینهٔ پاک‌سازی کامل در صفحهٔ پروفایل استفاده کن. این کار مخزن رمزگذاری‌شده و کلید رمزگذاری Mini Arcade را حذف می‌کند. پاک کردن دادهٔ سایت/تلگرام نیز نسخهٔ محلی را از بین می‌برد.
